# Swapnil Sanjeev — Portfolio (Final Clean Package)

Open `index.html` in a browser to view the portfolio. For reliable local testing and notebook downloads, serve this directory with a local HTTP server (for example `python -m http.server 8000`), then open `http://localhost:8000`.

The package contains only site source files, directly referenced images/graphics, the linked notebook and the resume PDF. External Google Fonts, GitHub, and social links require internet access.

Future projects can be added to the Projects section and the JavaScript case-study data.
